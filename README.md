# Service Request Management System

A Java-based system for managing campus service requests using different data structures.

## Features

- **Simple Queue:** Add and process service requests based on the First-In, First-Out (FIFO) principle, without considering priority.
- **Priority Queue:** Add and process service requests according to their priority rather than their arrival order.
- **Deque (Double-Ended Queue):** Add and remove service requests from both the front and rear of the queue.
- **Request Processing:** Process service requests using the three queue implementations: Simple Queue, Priority Queue, and Deque.
- **Undo Functionality:** Store insertion and processing operations in a Stack to allow users to undo previously performed operations.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures

## Data Structures

- Simple Queue
- Priority Queue
- Deque (Double-Ended Queue)
- Stack
- Array
- Linked List
